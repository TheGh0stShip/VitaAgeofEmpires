# Port coverage (patched Rise of Rome 1.0a)

Generated by `tools/port_worklist.py` (regenerate after each sweep). It
needs the local Ghidra exports in `build/decompile` and, for revision
mapping, `tools/revision_match.py`.

## How it is counted

- **Game code.** The `.text` section below the hand-written assembly module
  (`0x00524e90`) and the Visual C runtime (`0x00525c24` on, including
  compiler-generated unwind funclets from `0x00531000`). Function sizes run
  to the next function start, padding included.
- **Cited.** A function's start address appears in `src/` or `include/`.
  Disc-RoR and patched-base-1.0c addresses count through
  `tools/revision_match.py`:
  - exact matches of normalized instructions, kept in link order as
    anchors;
  - between anchors, mutual best instruction-multiset matches (similarity
    at least 0.6).

  The match reproduces all 13 function pairs in `docs/ror_revision_map.tsv`.
- **Estimate only.** Citations are not revision-tagged, so this is an
  estimate, not proof of translation. Original-behaviour claims still need
  evidence and tests.
