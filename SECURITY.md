# Security policy

This is a research and homebrew project, not a security-supported game release.

## Reporting a vulnerability

Please do not post exploitable details, malicious save files, or weaponized
proofs of concept in an issue. This repository is currently private, so
GitHub's private vulnerability-reporting form is unavailable. Contact the
maintainer through [their GitHub profile](https://github.com/TheGh0stShip)
before disclosure. Include the affected revision, build/configuration, impact,
and a minimal safe reproduction. Do not include original commercial game
files.

If the issue is a regular bug in reconstructed behavior or build tooling, use
the public bug-report issue template instead.

## Scope

Reports should concern code and tools in this repository. Original game files
are not distributed here and are outside the project's control.
